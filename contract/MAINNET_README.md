## Quick Deploy

### 1. Deploy Contracts

```bash
cd contract
./deploy_mainnet.sh
```

**What happens**:
- Script asks for confirmation (type `yes`)
- Declares Organization contract
- Declares OrganizationFactory contract
- Deploys OrganizationFactory instance
- Saves deployment info to `deployments/mainnet_deployment.json`
- Prints Voyager links and next steps

### 2. Update Configuration

After deployment completes, update `frontend/.env.local`:

```bash
# Copy the factory address from deployment output
# Then update the file:
NEXT_PUBLIC_MAINNET_ORGANIZATION_FACTORY_ADDRESS=[FACTORY_ADDRESS]
```

### 3. Update Documentation

Update `contract/DEPLOYED_ADDRESSES.md`:
- Replace `[PENDING DEPLOYMENT]` with actual addresses
- Add Voyager links
- Update deployment date

### 4. Test with Small Amounts

Create a test organization:
- Use minimal wBTC (0.0001 wBTC ≈ $10)
- Test all core functions
- Verify events on Voyager

## Troubleshooting

### "Insufficient balance"
→ Add more ETH to your account

### "Class already declared"
→ This is OK, script will use existing class hash

### "Transaction reverted"
→ Check Voyager for error details

### "RPC connection failed"
→ Check internet connection, try again
